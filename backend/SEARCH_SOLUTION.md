## 🔍 搜索功能特点

### 1. 智能匹配
- ✅ 部分匹配（如"вернад"匹配"Вернадского"）
- ✅ 不区分大小写
- ✅ 多语言支持（俄/英/中）
- ✅ 搜索关键词匹配

### 2. 快速响应
- 本地数据库搜索：< 10ms
- 无需等待 Yandex API
- 即时返回结果

### 3. 完整信息
返回的每个站点包含：
- `id`: 站点 ID（用于获取实时到站信息）
- `name`: 俄语名称
- `nameCn`: 中文名称
- `nameEn`: 英文名称
- `address`: 完整地址
- `coordinates`: GPS 坐标
- `href`: API 链接

## 📝 如何添加更多站点

### 方法 1: 手动添加（推荐用于常用站点）

编辑 `/backend/src/data/moscowStops.json`:

```json
{
  "stops": [
    {
      "id": "stop__新站点ID",
      "name": "站点俄语名称",
      "nameEn": "Station English Name",
      "nameCn": "站点中文名称",
      "address": "Москва, 完整地址",
      "coordinates": [经度, 纬度],
      "searchKeywords": ["关键词1", "关键词2", "keyword3"]
    }
  ]
}
```

### 方法 2: 从 Yandex Maps 获取站点信息

1. **打开 Yandex Maps**:
   ```
   https://yandex.ru/maps/213/moscow/
   ```

2. **搜索地址**（如"Проспект Вернадского, 33"）

3. **点击地图上的公交站点图标**（蓝色巴士）

4. **从 URL 复制 stopId**:
   ```
   https://yandex.ru/maps/.../stops/stop__9644561/
                                    ^^^^^^^^^^^^
                                    这是 stopId
   ```

5. **添加到数据库**

6. **重启服务器**:
   ```bash
   pkill -f "node src/app.js"
   node src/app.js &
   ```

```
用户搜索请求
    ↓
```
